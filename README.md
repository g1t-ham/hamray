# hamray

**hamray** — модификация Android-клиента на основе Exclave и часть проекта **Great User Team**.

- Репозиторий: https://github.com/g1t-ham/hamray
- Основа: [Exclave](https://github.com/feiyuang/Exclave)
- Планируемая дополнительная функция: профили ByeDPI с вводом CLI-стратегии.
- WDTT пока не входит в объём работ.

## Статус

Это рабочая подготовка проекта, а не готовый релиз. Функции нельзя считать реализованными до завершения интеграции и проверки на устройстве.

### План работ

1. Сохранить основную архитектуру и возможности Exclave.
2. Применить название и иконку hamray.
3. Сохранить Material You / динамические цвета на совместимых версиях Android и светлую/тёмную тему на остальных.
4. Добавить профили ByeDPI: ввод CLI-стратегии, сохранение нескольких профилей, выбор, редактирование и удаление.
5. Добавить маленький «Тихий пульс» только при подтверждённом активном соединении.
6. Обновить экран «О приложении»: hamray, ссылка на этот репозиторий и Great User Team.
7. Проверить сборку, запуск и работу сервисов и документировать ограничения.

## Ограничение исходной базы

Предоставленный архив — декомпилированный APK для Apktool M. Он содержит Android-ресурсы, манифест, DEX-файлы и нативные компоненты, но не является полным проектом Android Studio и не содержит декодированных Smali. Поэтому правки ресурсов сами по себе не добавляют новую логику. Для реализации ByeDPI нужна отдельная интеграция движка и сервисной части с последующим тестированием на устройстве.

## Сборка и распространение

До появления проверенного воспроизводимого процесса сборки этот репозиторий не является релизом и не предоставляет готовый APK. Не публикуйте сборки как рабочие, пока функции не проверены.
